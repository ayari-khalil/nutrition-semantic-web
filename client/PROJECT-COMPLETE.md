## 🎬 Pour Démarrer

### 1. Démarrer le Frontend

```bash
cd client
npm start
```

→ Ouvert sur http://localhost:3000

### 2. Démarrer le Backend (séparément)

```bash
cd ../Backend
python app.py
```

→ API sur http://localhost:5000

### 3. Tester l'Application

1. Ouvrir http://localhost:3000
2. Basculer en dark mode
3. Cliquer sur une question d'exemple
4. Voir les résultats s'afficher
5. Trier les colonnes
6. Exporter en CSV
7. Copier le SPARQL
